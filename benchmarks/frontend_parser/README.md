# Frontend parser in Gossamer

Two Gossamer ports of `gossamer_parse::parse_source_file`, kept as a
benchmark of tree-shaped Gossamer code rather than as a frontend `gos` uses.
Each parses a file and writes the postcard blob of the raw `SourceFile` the
Rust parser builds for the same text, node for node: ids, spans, desugarings,
and parse diagnostics. When they were written, both produced the Rust
parser's blob byte for byte on every `.gos` file of the repository and the
frozen build corpus (1,373 files). Nothing keeps them in step with the Rust
parser since; a grammar change that is not ported to them makes their blob
drift, not their timings meaningless.

- `idiomatic/` builds the tree with ordinary structs and enums (`ast.gos`,
  generated by `cargo xtask schema` from the blob's serde types). Every node
  is a counted heap object.
- `flat/` builds the same tree as records of words in one vector
  (`tree.gos`): a node names its children by index, so building the tree
  allocates nothing per node and freeing it frees one vector. It carries its
  own encoder.

## Running

```sh
(cd idiomatic && gos build --release)
(cd flat && gos build --release)
PP_FILE=path/to/file.gos PP_REPS=200 idiomatic/target/release/frontend-parser-idiomatic
PP_FILE=path/to/file.gos PP_REPS=200 PP_ARENA=1 idiomatic/target/release/frontend-parser-idiomatic
PP_FILE=path/to/file.gos PP_REPS=200 flat/target/release/frontend-parser-flat
```

`PP_OUT` names a file for the last parse's blob and diagnostics, so the
variants can be compared with `cmp`. `PP_ARENA=1` runs each idiomatic parse
inside an `arena { }`. Time with wall clock: arenas fall back to counted
objects under valgrind, so instruction counts cannot measure them.

## Results (0.72.0, `postwisp/src/main.gos`, 205 KB)

| Variant | Per parse and encode | Peak memory |
|---|---|---|
| idiomatic | 8.4 ms | 19.6 MB |
| idiomatic in `arena { }` | 5.7 ms | 15.3 MB |
| flat | 3.6 ms | 12.2 MB |

Wired into `gos check` in place of the Rust parser, the flat port put a cold
check at 1.07x to 1.41x the Rust frontend's wall time across the build
corpus. The gap between the idiomatic and flat rows is what reference
counting a tree costs today; language and runtime work that narrows it shows
up here first.
